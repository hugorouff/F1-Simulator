# Python du F1 Simulator

Le sous-projet `f1-race-replay` est récupéré depuis le dépôt public original :
`https://github.com/IAmTomShaw/f1-race-replay`

Le script `../scripts/install-f1-race-replay.ps1` effectue le clone dans `python/f1-race-replay` sans réécrire son code.

Les futurs modules du moteur de simulation personnalisé peuvent être ajoutés à côté, puis produire des frames compatibles avec le replay.
